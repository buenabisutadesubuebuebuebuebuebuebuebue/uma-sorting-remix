# Uma Sorting Remix

A very simple tampermonkey userscript for editing an existing [Snep Uma Sorter](https://snep.pw/uma/sorter/) result without repeating the entire sorting process.

Saving creates a new result. Your original result is not changed.




Simply install [Tampermonkey](https://www.tampermonkey.net/) in your browser then load this script.

Your Snep result page, such as `https://snep.pw/uma/sorter/result/.` will have a button called "Edit This Sorting" now. You can drag a uma to change her ranking, or add new added umas to your old result.
